# Intro 

NOVA Autonomous Car is a open-source research project for UTD students to make a fully autonomous car. 

![image](https://github.com/user-attachments/assets/b4d89711-5a3e-422b-a740-eb59b4545703)

So we just bought a random EV, and put a lot of things on there featuring a CAN, OBC, LiDAR, radar, camera, and more sensors to help us localize, or utilized odometry and navigate the path. Of course, we need to be able to follow traffic laws, but we also need to follow the path. 

I personally work on a lot of the electrical/hardware stuff on this, to help facilitate the programming of the car, whether it be parametricization or developing our navigating document which can be found on GitHub or the internet.
